01

Какой формат выбрать?

QR-код подходит для ссылок и текста. Code 128 — для произвольных латинских обозначений. EAN и UPC нужны для числовых товарных кодов.

02

PNG или SVG?

PNG удобно вставить в документ. SVG можно масштабировать без потери чёткости и использовать для печати.

03

Перед печатью

Проверьте код камерой или сканером в его конечном размере. Контраст и свободное поле вокруг изображения влияют на считывание.
